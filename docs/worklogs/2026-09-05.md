## Implemented and locally verified

- Retain bounded, validated early inbound replies for up to 24 hours while a
  recent outbound receipt is pending. The exact inbox/thread receipt must bind
  before any connection changes. At most 20 pending events per inbox; expired
  entries are removed. Multiple replies and corrections are retained without
  regressing Connected.
- Exhausted receipt polling becomes `delivery_unknown`, with an owned, throttled
  check of the existing outbound. It cannot enqueue another email. Generic
  component failures without receipts are treated as uncertain delivery.
- Extend the existing AgentMail component patch with a stable HTTP transport
  `Idempotency-Key`, bound to the persisted outbound ID. No POST is permitted
  after 23 hours from enqueue. This is inside AgentMail's documented 24-hour
  idempotency retention window. Source and shipped dist are patched.
- Failed private pitches and clarification judgments can retry with a new
  request, preserving prior runs, request idempotency, ownership and a three
  attempts per ten minutes limit. Clarification retry retains the original
  private answer.
- Verified replies schedule a source-bound OpenAI excerpt summary and possible
  next step. Automatic work uses sponsor credentials, once per event, with a
  deployment budget. An explicit owned retry selects the current authenticated
  credential and binds the attempt/version. Summary failure never rolls back a
  reply or blocks continuation.
- Live memory can trigger the one allowlisted source and contextual match.
  Source results have a visible check time and an explicit refresh path after
  fifteen minutes; scans retain a global burst and daily budget.
- Sound cues follow subsequent live discoveries/replies/memory additions after
  a browser gesture, skip initial hydration, and honor mute and volume. Motion
  respects the user's reduced-motion setting through MotionConfig.
- Private rooms keep independent bearer keys and retain earlier room access on
  the same device. No prior conversation or remote asset is deleted.
