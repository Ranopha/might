## Implementation

- Added stable Convex Auth email/password accounts with a 12-character password
  minimum. The passkey package available during implementation was alpha/WIP,
  so it was not placed in the critical demo path.
- Added an authenticated same-origin credential exchange. It verifies a
  personal OpenAI project key with one small Responses request, AES-256-GCM
  encrypts it with user/version-bound additional data, and stores only sealed
  ciphertext plus last-four, model, timestamp, and provider response ID receipt
  metadata.
- Added linked-room ownership, cross-account rejection, rotate and delete
  controls, hourly/daily per-user use limits, and signed-out fallback to
  hackathon sponsor mode.
- Bound the credential ID and version to new Manifestation, Talk/Memory, world
  interpretation, Match, clarification, and pitch jobs. Firecrawl, AgentMail,
  memory privacy, and exact-payload send consent remain separate.
- Replaced the placeholder AI-access copy with a paper-room account and key
  cabinet that reports guest, linked, configured, last-used, rotate, delete,
  and sign-out states. Raw keys are not stored in browser state or storage and
  the input clears after each attempt.
